## 🚀 Projects

### 🔧 [Pipeline Intelligence Agent](https://github.com/mahitha-muppalaneni/pipeline-intelligence-agent)
A LangGraph multi-agent system that lets you ask your Azure Data Factory pipelines questions in plain English. Diagnoses failures, detects SLA breaches, and recommends fixes — using only free tools (Groq, ChromaDB, FastAPI, Streamlit, Docker).

> *"Why did the sales pipeline fail today?"* → root cause + SLA impact + action steps, instantly.

`LangGraph` `Groq Llama 3.3 70B` `ChromaDB` `FastAPI` `Streamlit` `Docker`

---

### 🛡️ [FinGuard Fraud Pipeline](https://github.com/mahitha-muppalaneni/finguard-fraud-pipeline)
Production-grade PySpark & Databricks pipeline modelled on Australian retail banking. Ingests 500K synthetic transactions through Bronze → Silver → Gold Medallion Architecture, with fraud feature engineering aligned to AUSTRAC typologies.

`PySpark` `Databricks` `Delta Lake` `Unity Catalog` `Python`

---

### 🔍 DocuQuery *(coming soon)*
Provider-agnostic agentic RAG system built with LangGraph, Qdrant, and hybrid BM25 + vector retrieval. Switch between Gemini, Azure OpenAI, or Ollama without touching your pipeline.

`LangGraph` `Qdrant` `BM25` `Gemini` `Azure OpenAI` `Ollama`
